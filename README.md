# Neural Network Implementation from Scratch using MNIST

## Course
Generative AI Lab

## Objective

The objective of this assignment is to implement a feedforward neural network
from scratch in Python without using built-in deep learning libraries.

## Dataset

MNIST Handwritten Digit Dataset.

The task is to classify handwritten digits from 0 to 9.

## Models Implemented

### Model 1
- Input Layer: 784 neurons
- Hidden Layer: 128 neurons
- Activation: ReLU
- Output Layer: 10 neurons
- Output Activation: Softmax

### Model 2
- Input Layer: 784 neurons
- Hidden Layer 1: 128 neurons
- Activation: ReLU
- Hidden Layer 2: 64 neurons
- Activation: ReLU
- Output Layer: 10 neurons
- Output Activation: Softmax

## Algorithms Implemented From Scratch

- Forward propagation
- ReLU activation
- Softmax activation
- Cross-entropy loss
- Backpropagation
- Gradient descent
- Mini-batch training
- Prediction
- Evaluation metrics
- Confusion matrix

## Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix
- Training and validation loss
- Training and validation accuracy
- Number of parameters
- Training time
